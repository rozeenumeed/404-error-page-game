# 🎮 404 Error Page — Memory Matching Game

A customized and interactive 404 Error Page built using HTML, CSS, and JavaScript. Instead of showing a simple error message, this page includes a fun **Memory Matching Cards Game** to make the user experience more engaging.

## ✨ Features

- 🚫 Custom 404 error page design
- 🎮 Interactive memory matching card game
- 🃏 Flip cards to find matching pairs
- 🧠 Improves memory and concentration
- 🎨 Custom styling and animations
- 📱 Responsive user interface
- 🏠 Navigation option to return to the homepage

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, layout, and card animations
- **JavaScript** — Game logic, card flipping, and matching functionality

## 🎯 How to Play

1. Click on a card to reveal it.
2. Click another card to find its matching pair.
3. Match all pairs to complete the game.
4. Enjoy the interactive experience on the 404 error page.
